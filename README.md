# IBS

A desktop app for tracking and managing IBS, built for an Indian user and an Indian diet.

It logs the things that drive IBS day to day:

- **Food**: Indian home-cooked dishes, Indian portion sizes and FODMAP content
- **Bowel movements**: Bristol stool scale
- **Symptoms**: pain, bloating, gas, acidity and more
- **Stress and mood**
- **Water intake**
- **Sleep**
- **Exercise**: including yoga, walks and pranayama

It then links what you ate and did to how you felt afterwards.

## Status

Early stage. Competitor research is done; the app itself hasn't been built yet.

### Key findings

- No existing app understands Indian home cooking: dal, sabzi, roti, chai, or the onion and garlic in a tadka.
- Only two India-built IBS apps exist (Gut-Buddy, Guto), and both are very small.
- Users drop apps when logging is slow, or when the "insights" only tell them what they already knew.
- Stress is usually logged as a single daily number, and gut-brain therapy is kept apart from tracking.
